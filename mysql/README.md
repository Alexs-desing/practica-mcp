# Base de datos `lavado_autos` en MySQL 8.0+

Script equivalente al esquema `lavado_autos` de PostgreSQL/Supabase, adaptado a
MySQL y probado sobre **MySQL 8.0.46**.

Contiene **12 tablas**, **13 claves foráneas** y **144 filas** de ejemplo.

## Archivo

| Archivo | Contenido |
|---|---|
| `lavado_autos_mysql.sql` | `CREATE DATABASE`, 12 tablas, FK, checks, índices, 144 filas y consulta de verificación |

## Cargar en MySQL Workbench

1. Abre MySQL Workbench y conéctate a tu servidor local:
   - **Host:** `127.0.0.1`
   - **Port:** `3306`
   - **User:** `root` (o un usuario con permiso `CREATE DATABASE`)
2. Menú **File → Open SQL Script…** y elige `mysql/lavado_autos_mysql.sql`.
3. Pulsa **Execute SQL Script** (icono del rayo con el mundo, o `Ctrl+Shift+Enter`).
4. En el panel **SCHEMAS** de la izquierda pulsa refrescar (`F5`).
5. Aparecerá la base **`lavado_autos`**. Haz doble clic para seleccionarla.

La última consulta del script devuelve el conteo por tabla, así que verás el
resultado directamente en la pestaña de resultados.

## Cargar desde terminal

```bash
# Opción 1: como root del sistema (si MySQL usa auth_socket)
sudo mysql < mysql/lavado_autos_mysql.sql

# Opción 2: pidiendo la contraseña de root de MySQL
mysql -u root -p < mysql/lavado_autos_mysql.sql
```

## Usuario para MySQL Workbench (Ubuntu)

En Ubuntu, el usuario `root` de MySQL suele usar autenticación por socket
(`auth_socket`), así que Workbench —que conecta por TCP— no puede entrar como
`root` aunque escribas bien la contraseña. La forma más rápida es crear un
usuario administrador solo para este esquema:

```bash
cd /home/ale/Escritorio/Practica1_Oc
bash scripts/cargar_lavado_autos_mysql.sh
```

El script hace todo esto:

- Carga `lavado_autos_mysql.sql` con `sudo mysql` (te pedirá tu contraseña de sudo).
- Crea el usuario **`lavado_admin`@`localhost`**.
- Genera una contraseña aleatoria y la guarda en
  `~/.secrets/mysql_lavado_admin_password` con permisos `600`.
- Le da `ALL PRIVILEGES` solo sobre `lavado_autos.*`.
- Da `SELECT` a `mcp_user` para que OpenCode pueda verificar los datos.
- Prueba la conexión y muestra el conteo de las 12 tablas.

Datos para la conexión de Workbench:

```text
Host:            127.0.0.1
Port:            3306
User:            lavado_admin
Default Schema:  lavado_autos
Password:        cat ~/.secrets/mysql_lavado_admin_password
```

Si ya tienes un usuario de MySQL con contraseña y permisos suficientes, puedes
usarlo directamente y ejecutar solo el archivo SQL.

## Comprobar que quedó bien

```sql
USE lavado_autos;

SELECT 'clientes' AS tabla, COUNT(*) AS filas FROM clientes
UNION ALL SELECT 'vehiculos', COUNT(*) FROM vehiculos
UNION ALL SELECT 'servicios', COUNT(*) FROM servicios
UNION ALL SELECT 'empleados', COUNT(*) FROM empleados
UNION ALL SELECT 'insumos', COUNT(*) FROM insumos
UNION ALL SELECT 'promociones', COUNT(*) FROM promociones
UNION ALL SELECT 'citas', COUNT(*) FROM citas
UNION ALL SELECT 'ordenes', COUNT(*) FROM ordenes
UNION ALL SELECT 'orden_detalle', COUNT(*) FROM orden_detalle
UNION ALL SELECT 'pagos', COUNT(*) FROM pagos
UNION ALL SELECT 'consumo_insumos', COUNT(*) FROM consumo_insumos
UNION ALL SELECT 'orden_promociones', COUNT(*) FROM orden_promociones;
```

Resultado esperado: 12, 12, 10, 10, 10, 10, 12, 12, 20, 12, 14 y 10.

Otras consultas útiles:

```sql
-- Órdenes con cliente y vehículo
SELECT o.id,
       CONCAT(c.nombre, ' ', c.apellido) AS cliente,
       v.placa,
       CONCAT(v.marca, ' ', v.modelo) AS vehiculo,
       o.estado, o.subtotal, o.descuento, o.total
FROM ordenes o
JOIN clientes  c ON c.id = o.cliente_id
JOIN vehiculos v ON v.id = o.vehiculo_id
ORDER BY o.id;

-- Ingresos aprobados por método de pago
SELECT metodo, COUNT(*) AS pagos, SUM(monto) AS total
FROM pagos
WHERE estado = 'aprobado'
GROUP BY metodo
ORDER BY total DESC;

-- Servicios más vendidos
SELECT s.nombre, SUM(d.cantidad) AS veces, SUM(d.subtotal) AS importe
FROM orden_detalle d
JOIN servicios s ON s.id = d.servicio_id
GROUP BY s.nombre
ORDER BY importe DESC;
```

## Modelo de datos

```text
clientes ──< vehiculos ──< citas
    │            │
    │            └──< ordenes >── empleados
    │                    │
    │                    ├──< orden_detalle >── servicios
    │                    ├──< pagos
    │                    ├──< consumo_insumos >── insumos
    │                    └──< orden_promociones >── promociones
    └────────────────────┘
```

Reglas destacadas:

- `ordenes.total <= subtotal` y en los datos `total = subtotal - descuento`.
- `pagos` con `estado = 'aprobado'` exige `fecha_pago`.
- `orden_detalle` no repite el mismo servicio en una orden.
- `consumo_insumos` no repite el mismo insumo en una orden.
- Borrados: `CASCADE` en dependencias de la orden y `RESTRICT` en catálogos.

## Diferencias con la versión PostgreSQL

| PostgreSQL | MySQL |
|---|---|
| `GENERATED BY DEFAULT AS IDENTITY` | `AUTO_INCREMENT` |
| `TIMESTAMPTZ` | `DATETIME` |
| `TEXT` con `CHECK (valor IN (...))` | `ENUM(...)` |
| `BOOLEAN` | `TINYINT(1)` |
| `NUMERIC(10,2)` | `DECIMAL(10,2)` |
| `setval(...)` al final del seed | no hace falta; MySQL ajusta el `AUTO_INCREMENT` |

> Los `CHECK` necesitan **MySQL 8.0.16 o superior**. En MySQL 5.7 se aceptan pero
> no se aplican.

## Usuario para la aplicación (opcional)

El script no crea usuarios. Si vas a conectar una app en lugar de usar Workbench
como root, crea un usuario con permisos mínimos:

```sql
CREATE USER 'lavado_app'@'localhost' IDENTIFIED BY 'cambia_esta_contrasena';
GRANT SELECT, INSERT, UPDATE, DELETE ON lavado_autos.* TO 'lavado_app'@'localhost';
FLUSH PRIVILEGES;
```

No uses `root` para la aplicación.

## Nota sobre el MCP de MySQL

El MCP de MySQL configurado en OpenCode es **solo lectura** y el usuario
`mcp_user` no tiene permiso para crear bases de datos. Por eso la creación se
hace con este script desde **MySQL Workbench** o desde la terminal como root.
